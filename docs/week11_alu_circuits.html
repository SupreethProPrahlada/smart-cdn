1. Register file without ALU

An 8 × 16 register bank has two asynchronous read ports and one synchronous write port. Register 0 is held at zero; registers 1–7 store data. The write address is accepted only when wr=1 and wr_addr≠0.

Register file behavior

resetwrwr_addrClock eventRegister bank action
1XXposedge clkClear R1–R7 to 0; R0 remains 0
00Xposedge clkNo write; retain stored values
011–7posedge clkR[wr_addr] ← d_in
010posedge clkIgnore write; R0 remains 0

Read outputs follow their selected addresses asynchronously. Reading address 0 returns 0 on either port.

2. Register file with ALU

The ALU receives the two register-file read values. Its result and the external input data feed a write-data selector: sel=1 selects the ALU result; sel=0 selects d_in. A carry output is captured in a clocked carry register.
