# Experiment results

New trusted runs are generated by `tests/run_scenarios.py experiments` in both dynamic and static controller modes.

- `data/experiments.csv`: measured per-client records
- `data/client-transfers.csv`: optional log from standalone client runs; ignored by Git
- `reports/summary.md`: generated comparison table
- `figures/`: generated response-time, throughput, and success-rate plots
- `archive/unverified/`: prior run files retained for reference; these have unclear provenance or were collected with earlier code and are excluded from reports

Run `uv run python tests/make_graphs.py` after completing both modes to regenerate the report and figures.
